# 看病用户端 · 导诊台 MVP

与医生端（medical-assistant-*）并列的患者端。免责：辅助导诊，不替代面诊；急危重症提示立即急诊。

## 范围（最小可用）
1. 症状导诊：采集主诉/时长/部位 → 推荐科室 1–3 个 + 是否建议急诊/线上问诊
2. 预约挂号入口：选院区/科室/医生时段（Mock 号源即可）→ 提交预约单 → 状态页
3. 智能问诊对话：多轮澄清症状 → 小结 + 导诊结果回写；可转预约

## 页面
- 首页导诊台入口
- 症状问卷 / 对话问诊
- 导诊结果（科室、急诊提示、下一步）
- 预约流程（科室→医生→时段→确认）
- 我的预约（演示列表）

## 不做
HIS 真对接、支付、处方、医生端改动、实名认证生产级

## 技术建议
- 前端：可点击 Web，中文、清晰医疗风
- 后端：可扩 medical-assistant-api 或新服务 /workspace/medical-patient-api（FastAPI）
- AI：OpenAI 兼容，Key 用 LLM_API_KEY；失败降级规则/Mock

## 增量（2026-10-08）

- 移动端：H5/PWA（可加到主屏），暂不做原生壳
