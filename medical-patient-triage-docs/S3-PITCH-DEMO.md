# S3 路演 PPT 与演示脚本

## 背景
双端医疗 AI 演示（患者端 + 医生端）已具备：导诊/问诊/预约、医生工作台、慢病、运营看板、部署打包、AI 安全护栏。需要一套可对外讲的路演材料和可照着点的演示脚本，支撑投资人/医院演示。

## 目标
1. 一份 8–12 页路演 PPT（中文），讲清问题、方案、演示路径、护栏与下一步。
2. 一份 5–8 分钟黄金路径演示脚本，按点击顺序写，含旁白和兜底话术（模型慢/Mock/红旗弹窗）。

## 需求
### P0
- **路演 PPT**
  - 建议页结构：封面 → 痛点 → 产品全景（患者/医生） → 黄金路径演示预告 → 护栏与合规 → 技术架构一页 → 里程碑与现状 → 下一步与诉求。
  - 截图用现成 `/workspace/s2-shots/` 与实机页面；不写虚假数据。
  - 交付：用户选定的平台（PPTX / Google Slides 等）+ 可下载文件。
- **演示脚本** `DEMO-SCRIPT.md`
  - 账号：医生 doctor/demo123；患者端免登录演示路径。
  - 顺序建议：患者导诊（普通症状）→ 红旗胸痛弹窗 → 预约 → 医生工作台鉴别诊断 → 一键病历 → 运营看板护栏计数 →（可选）compose 一键起。
  - 每步：要点击哪里、期望画面、旁白 1–2 句、异常兜底（503/Mock/约 10s 等待）。
  - 标注预计耗时，合计 ≤8 分钟。

### P1
- 一页「竞品对比」可选。
- 英文摘要一页可选。

## 非目标
不做视频录制、不做印刷物料、不改产品功能。

## 成功指标
- 按脚本走通一遍无卡死；PPT 与脚本口径一致；评审后可直接用于路演。

## 待确认
- PPT 平台与是否有模板。
